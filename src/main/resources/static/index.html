6AI 要素抽取与风险审查

核心机制：证据对齐。模型给出的每条引文都要回到原文核对—— 定位得到才保留，定位不到就标为证据不匹配、不进报告正文。 这条链路默认走 Mock 桩（AI_ENABLED=false），零额度消耗。

看两处对比即可理解本项目的核心设计：
· 要素抽取里，引文定位不到的字段会落库为 UNKNOWN（而不是被丢掉）， 这样"抽过但失败"与"从没抽过"可以区分。
· AI 审查里，所有条目的状态都是候选态（PENDING / LOW_CONFIDENCE / EVIDENCE_MISMATCH）， 没有"已生效"这个状态——采信权归人工。
