# 合同智能审查平台 · 项目索引

> [!tip] **休息后回来先看**：[快速回顾 RESTART-HERE.md](RESTART-HERE.md) —— 一分钟回到状态，不用翻遍全部文档。

## 一句话说明

给企业法务一个**能把合同审查过程和结论留痕**的工作台：上传合同 → 系统提取要素 → 确定性规则校验 → AI 辅助识别风险条款并给出原文证据 → 低置信度项转人工复核 → 输出可追溯的审查报告。

## 项目定位（对面试官的一句话）

> 一个 Java 全栈的合同审查平台，核心工程价值在于**把"概率性的 AI 判断"和"确定性的规则校验"分开治理**：AI 只负责产出带证据和置信度的候选结论，是否采信由规则和人工决定。
