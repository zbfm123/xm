## 这个项目的核心是什么（一句话）

> **不是"接了 AI"，而是给概率性的 AI 输出加上工程约束。**

AI 只能产出**带原文证据和置信度的候选结论**；能不能采信，由**确定性规则**和**人工**决定。

## 三个「绝不砍」的能力（面试就讲这三个）

### ① 证据对齐 —— 让模型的错误可检测

大模型会幻觉出原文里没有的条款。所以每条引文都必须**回到原文机器校验定位**：

| 级别 | 策略 | 权重 |
| --- | --- | --- |
| `EXACT` | 逐字命中 | 1.0 |
| `NORMALIZED` | 归一化后命中，**区间回映射到原文坐标** | 0.9 |
| `FUZZY` | 编辑距离 ≥ 0.80 | 0.7 |
| `NONE` | 未命中 | 0 |

**三条绝不妥协的纪律**：
1. 找不到 → **不返回任何位置**（给个"差不多"的区间比不给更糟）
2. 多处命中且无法消歧 → 判失败
3. 引文过短（< 6 字）→ 判失败

代码：`extract/evidence/`；任务卡：[T-013](tasks/T-013-evidence-alignment.md)

### ② 只追加审计 —— 谁做的决定

AI 给候选，**人做决定**，决定被永久留痕。三层保障：

| 层 | 手段 | 防住什么 |
| --- | --- | --- |
| 接口 | Mapper **只有 insert/find** | 有反射测试强制，加了 update/delete 就构建失败 |
| 数据库 | `BEFORE UPDATE/DELETE` **触发器** | 手工 SQL、运维脚本 |
| 密码学 | **哈希链** | 有 root 权限的人 |

**诚实说明边界**：哈希链防**篡改**，**不防抵赖**（知道算法的人可以重算整条链）。

代码：`review/`；任务卡：[T-018](tasks/T-018-append-only-audit.md)

### ③ 降级 —— AI 挂了系统还能用

`AI_UNAVAILABLE` **不是终态**，它有边通向 `AWAITING_REVIEW`。

**如果把它设成失败终态，就等于"AI 挂了整份审查就废了"**——规则引擎做得再准也没有意义，因为用户根本走不到看结论那一步。

演示方式：
```powershell
$env:AI_ENABLED="true"; $env:AI_CLIENT_MODE="unavailable"; .\run-dev.ps1
```
降级是**确定性**的，不依赖拔网线。

代码：`aireview/client/UnavailableAiClient.java`；任务卡：[T-019](tasks/T-019-ai-degradation.md)

## 环境事实（踩过坑的，别重复踩）

| 事实 | 说明 |
| --- | --- |
| `java` on PATH 是 **JDK 1.8** | 必须设 `JAVA_HOME=D:\java\jdk-21`；`.mvn/jvm.config` 已兜住 Maven |
| MySQL `localhost:3306` / 库 `contract_review` / `root` / `123456` | Windows 服务 `MySQL80` |
| Redis `127.0.0.1:6379` / 口令 `123456` | Windows 服务 `Redis`，版本 3.2.100（够用） |
| **没有 Docker**，也不需要 | MySQL/Redis 已是本机服务 |
| `.ps1` **必须带 UTF-8 BOM** | 否则 PowerShell 5.1 按 GBK 解码、中文注释破坏语法（`push.ps1` 已双向校验） |
| `.java`/`.yml`/`.sql` **不能带 BOM** | 否则 `javac` 报"需要 class、interface、enum 或 record"（`push.ps1` 已拦） |
| 8080 被占用 | `Get-Process java \| Stop-Process -Force` |
